# ArtCreation React website starter

Run `npm install`, then `npm run dev`. Build for deployment with `npm run build`.

Includes responsive React/Vite pages for Home, About, Products, Engineering & Manufacturing, Industries, Projects, Catalogue, and Contact/RFQ. Product search/filter, responsive navigation, enquiry validation and email-draft workflow are included.

Before going live: replace Unsplash demo photography with approved company/product images, add the approved logo and catalogue PDF, confirm copy/contact details, and connect a real form backend for direct submission and secure file upload. The RFQ form currently opens the visitor's email app; it does not send to a server. Project cards are illustrative application areas, not claims of completed client projects. Product content is based on the provided Website Content document.
